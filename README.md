# Прогнозирование цен на жильё: линейная регрессия

## О задаче
Датасет `sales.csv` содержит информацию о продажах квартир (1460 записей).
Целевая переменная — **SalePrice** (цена продажи).

## Ключевая проблема
Распределение `SalePrice` сильно скошено вправо. Линейная регрессия с MSE
чувствительна к выбросам, поэтому в работе применяется
**логарифмирование таргета** и анализируется гетероскедастичность остатков.

## Структура работы
1. Импорт библиотек
2. Загрузка и первичный анализ (EDA)
3. Предобработка 
4. Разделение данных
5. Обучение моделей
6. Оценка качества (MAE, MSE)
7. Анализ остатков и проверка гетероскедастичности
8. Выводы
